System Information

Live weather: This browser-only version fetches weather data from Open-Meteo. Their forecast API supports multiple coordinates in one request and provides current/hourly weather variables. The dashboard refreshes its API feed every 60 seconds and displays an explicit API health state.

IoT telemetry: Sensor cards intentionally use a visible demo stream until real ESP32/LoRa/MQTT/REST/WebSocket data is connected. They are not presented as physical sensor readings.

Map: Leaflet renders OpenStreetMap tiles. The search box uses OpenStreetMap Nominatim search. Internet access is required for external libraries, map tiles and live API data.
